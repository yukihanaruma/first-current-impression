# 첫인상 · 현인상 (한 페이지 버전)

## 기능
- 참가자/진행자/공개 익명 게시판이 모두 `index.html` 한 페이지에 있습니다.
- 참가자는 같은 링크에 접속해 글을 제출하고, 진행자가 공개한 글을 모두 읽을 수 있습니다.
- 진행자 관리 기능은 우측 상단 `진행자 로그인`에서 비밀번호로 열 수 있습니다.
- OBS 브라우저 소스에는 사이트 메인 주소 하나를 등록하면 됩니다. 공개 게시판을 포함한 페이지 전체가 방송 화면에 표시됩니다.

## 실행
1. Node.js 18 이상 설치: https://nodejs.org/
2. 이 폴더에서 터미널을 열고 실행:
   ```
   npm install
   ```
3. 관리자 비밀번호 설정 후 실행 (PowerShell):
   ```
   $env:ADMIN_PASSWORD="원하는_긴_비밀번호"
   npm start
   ```
   CMD:
   ```
   set ADMIN_PASSWORD=원하는_긴_비밀번호
   npm start
   ```
4. 사이트: `http://localhost:3000`

## 진행
1. 오른쪽 위 `진행자 로그인`을 눌러 관리자 비밀번호로 로그인합니다.
2. 참가자 이름을 한 줄에 하나씩 등록합니다.
3. 주인공을 선택하거나 랜덤 선정합니다.
4. `작성 시작`을 누르고 사이트 링크를 참가자들에게 공유합니다.
5. 참가자들이 첫인상/현인상을 제출합니다.
6. `작성 마감 · 공개 준비`를 눌러 제출을 닫습니다.
7. 미공개 글을 확인하고 `모두에게 공개`를 누르면 공개 게시판에 글이 나타납니다. 모든 참가자가 같은 페이지에서 읽을 수 있습니다.

## OBS
- OBS에서 브라우저 소스를 추가하고 URL에 `http://localhost:3000`을 입력합니다.
- Width/Height는 방송 캔버스에 맞게 설정합니다 (예: 1920 x 1080).
- 이 방식은 사이트 페이지 전체를 방송에 띄웁니다. 진행자 로그인/관리자 패널이 화면에 보이지 않도록 하려면 로그인 후 해당 패널을 접거나, OBS용 별도 크롭/장면 구성을 해야 합니다. 기본 버전에서는 진행자 패널이 페이지 아래쪽에 있어 전체 페이지 캡처 시 보일 수 있으니, 방송 전 미리보기로 확인하세요.

## 인터넷 링크로 배포
`localhost`는 본인 PC에서만 접속됩니다. 원격 참가자가 접속하려면 Node.js 서버를 외부 호스팅에 배포하고 HTTPS 주소를 공유해야 합니다. 이 ZIP은 프로젝트 파일이며, 이미 공개된 인터넷 주소는 포함되어 있지 않습니다.

## 익명성 안내
- 서버는 작성자 이름을 글과 연결해 저장하지 않습니다.
- 참가자별 계정이나 일회용 토큰이 없어 이름을 바꿔 중복 제출하는 것을 완전히 막지는 못합니다.
- 데이터는 메모리에 저장되므로 서버를 재시작하면 초기화됩니다.
- 외부 배포 전 관리자 비밀번호를 바꾸고 HTTPS/남용 방지/영속 저장소를 추가하는 것을 권장합니다.

## 클릭 위주로 인터넷에 공개하기 (Render)
1. GitHub 계정에 로그인하고 새 저장소(repository)를 만듭니다.
2. ZIP 압축을 풀고 `server.js`, `package.json`, `render.yaml`, `public` 폴더 등 프로젝트 파일을 저장소 최상위에 올립니다. `public` 폴더 안 파일들은 `public` 폴더 안에 있어야 합니다.
3. https://render.com/ 에 가입/로그인한 뒤 **New + → Blueprint**를 선택하고 방금 만든 GitHub 저장소를 연결합니다.
4. Render가 `render.yaml`을 읽으면 서비스를 생성합니다. 환경 변수 `ADMIN_PASSWORD`는 Render에서 자동 생성하도록 설정되어 있습니다.
5. 배포가 끝나면 Render가 제공하는 `https://...onrender.com` 주소를 엽니다. 그 주소를 참가자들에게 공유하고, OBS 브라우저 소스에도 같은 주소를 입력합니다.

참고: 무료 서비스는 사용하지 않을 때 잠들 수 있어 첫 접속이 느릴 수 있습니다. 현재 버전은 글을 메모리에 저장하므로 서버가 재시작되면 데이터가 사라질 수 있습니다. 중요한 방송에 사용하기 전에는 테스트 방송을 먼저 해보세요.
